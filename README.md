# Arcade — сайт с мини-играми (реклама + ЮKassa)

Готовый сайт с тремя играми (Змейка, Тест реакции, Мемори), двумя рекламными блоками и приёмом платежей в рублях через ЮKassa.

**Важно без иллюзий:** код сам по себе денег не приносит. Доход = трафик × конверсия. Сайт закрывает техническую часть, остальное — твои аккаунты и привлечение людей.

## Структура

```
index.html        главная страница (игры, рекламные слоты, кнопки оплаты)
config.js         настройки фронта: apiBase, цена, ID рекламных блоков
js/games.js       три игры на чистом JS
js/app.js         навигация, реклама, логика оплаты
server/index.js   бэкенд ЮKassa (создание платежа, webhook, лицензии)
terms.html        условия и оферта (шаблон, требуется для ЮKassa)
privacy.html      политика конфиденциальности (шаблон)
```

## Запуск локально

Фронтенд — обычные статичные файлы:

```bash
python3 -m http.server 8080
# открой http://localhost:8080
```

Бэкенд оплаты:

```bash
cd server
cp .env.example .env   # вставь shopId и секретный ключ ЮKassa
npm install
node --env-file=.env index.js
```

В `config.js` укажи `apiBase: "http://localhost:3000"` для локальной проверки.

## Что нужно от тебя, чтобы пошли реальные рубли

1. **Статус для приёма денег.** Самозанятость (достаточно, оформляется в приложении «Мой налог») или ИП.
2. **ЮKassa.** Подключи магазин, пройди модерацию (нужны работающий сайт с офертой и контактами), возьми `shopId` и секретный ключ → в `server/.env`.
3. **Вебхук.** В личном кабинете ЮKassa укажи URL `https://твой-домен/api/payments/webhook` и событие `payment.succeeded`.
4. **Домен и хостинг.** Статику можно бесплатно на GitHub Pages (workflow уже в репо), бэкенд — любой VPS от ~200 ₽/мес. Для ЮKassa нужен свой домен, не `github.io`.
5. **Реклама.** Зарегистрируй сайт в Яндекс РСЯ (Рекламная сеть Яндекса), создай два блока и вставь их ID в `config.js`. Пока ID пустые — на месте рекламы серые заглушки.
6. **Трафик.** Без посетителей доход = 0 ₽. Рекламная сеть также требует минимального трафика для одобрения.

## Реалистичные цифры

Примерные ориентиры для развлекательного трафика в РФ (могут отличаться в разы):

| Посетители/мес | Реклама (~50–150 ₽ за 1000 просмотров) |
|---|---|
| 1 000 | ≈ 100–300 ₽ |
| 10 000 | ≈ 1 000–3 000 ₽ |
| 100 000 | ≈ 10 000–30 000 ₽ |

Донаты и Premium обычно дают конверсию 0,1–1% от аудитории.

## Безопасность

- Секретный ключ ЮKassa живёт только на сервере, в `.env` (в `.gitignore`).
- Сумма платежа валидируется на сервере — клиент не может купить Premium за 1 ₽.
- Статус платежа всегда перепроверяется запросом к API ЮKassa, а не берётся из тела вебхука.
- Для боевого запуска замени `data.json` на нормальную БД (SQLite/Postgres) и закрой вебхук проверкой IP ЮKassa.
